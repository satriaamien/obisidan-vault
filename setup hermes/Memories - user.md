## Preferensi Kolaborasi QA
- Saat saya memberikan spesifikasi (PRD/User Story) atau kode lokal untuk pembuatan test case, lakukan secara bertahap:
  1. Tampilkan hasil **Requirement Gap Analysis** terlebih dahulu jika ada spesifikasi yang ambigu atau belum lengkap.
  2. Tampilkan **Matriks Pendukung** (Collapsed Decision Table atau daftar State Transition) terlebih dahulu untuk saya tinjau.
  3. Setelah matriks saya setujui, baru konversikan menjadi **Tabel Test Case** lengkap dengan `Test Type` dan `Priority`.
